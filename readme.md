# Cell Gas Gateway State Detection Data Set VOC+YOLO format with 2105 images in 2 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 2105

Number of annotations (number of xml files): 2105

Number of annotations (number of txt files): 2105

Labeling category count: 2

Label category names (Note that the order of yolo format categories does not correspond to this, but is based on the classes.txt in the labels folder): ["close", "open"]

Number of boxes labeled in each category:

Close Frame Count = 3629

Number of open boxes = 9883

Total frame count: 13512

Image resolution: 640x640

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: The dataset does not have separate training, validation, and test sets; you need to partition them yourself.

Special : This dataset does not guarantee the accuracy of the trained models or weight files.
